# demo：把「+X% 的假超额」拆开看

一个**合成市场**上的可复现实验：真实 alpha 设为 **0**，然后逐条加上／去掉测量口径，
看同一份数据能被推到多远。

```bash
python demo/run_demo.py
```

固定随机种子（`SEED = 20261116`），每次跑出来的数字完全一样。

## 输出

```
步骤                                                  年化超额
------------------------------------------------------------
① 原样：幸存者池 / 18 组挑最好 / 策略不扣成本 / 基准零成本日再平衡           4.83%
② 修多重检验：18 组取中位数，不挑最好的一组                           2.59%
③ 修幸存者偏差：策略池含已退市股票                                 1.01%
④ 修成本：策略每期换仓扣双边成本                                 -3.40%
⑤ 修基准：日再平衡 → 买入持有（基准不再零成本全额换手）                    -3.98%
⑥ 修年化口径：两边统一几何年化                                  -3.95%
------------------------------------------------------------
合计变化                                              -8.78pp
```

## 每一步改了什么

| 步骤 | 做了什么 | 为什么它算错误 |
|---|---|---|
| ① | 只从「期末还活着」的股票池里选、18 组参数里挑最好的那组、策略不扣成本、基准每天全额换手却零成本 | 未来信息（幸存者池）＋多重检验＋成本不对称，三样同时偏乐观 |
| ② | 18 组取中位数，不挑最好 | 挑最好的那组等于对同一份数据做 18 次检验再报最大值 |
| ③ | 股票池含已退市标的 | 只用今天还在的股票回测过去，等于提前知道谁会死 |
| ④ | 策略每期换仓扣双边成本（佣金＋印花税＋滑点） | 不扣成本的策略收益不可执行 |
| ⑤ | 基准换成期初买入持有 | 日再平衡基准隐含每天全额换手，却按零成本算，和策略不对称 |
| ⑥ | 两边统一几何年化 | 算术／几何混用会在高波动下虚增年化 |

## 怎么读这个结果

- **①→⑥ 的 8.78pp 全是口径造成的**，因为真实 alpha 是 0。这就是「测量误差」四个字的实物。
- ⑥ 落在 −3.95% 不是 bug：零 alpha 的策略扣掉成本就是负的，这也是一种结论。
- 剩下那点数字随种子变化，**不要**把它当成任何真实策略的业绩。

## 它不证明什么

- 不是真实市场数据，不构成任何策略有效性的证据；
- 只演示**一个**合成市场、一种策略类型；
- 真实项目里的误差幅度与这里的数字不会相同（见主 README 的 E1–E9 实测表）。

## 和 `backtest_lint` 的关系

```bash
python demo/run_demo.py --demo-dir demo/_out
python -m backtest_lint --bundle demo/_out      # 需要把 csv/meta 改成 daily.csv / meta.json 的目录布局
```

`demo/_out/` 会导出 `naive_daily.csv` + `naive_meta.json` 与 `corrected_daily.csv` + `corrected_meta.json`，
前者送进体检工具是 **6 项阻断**（E2/E3/E4/E5/E8/E10），后者剩 **2 项**
（E7：t=0.40 不显著；E10：扣成本后 SR 为负、DSR=0.003——两者都是因为 alpha 本来就是 0）。
